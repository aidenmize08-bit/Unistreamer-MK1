BUILD THE APK (no installs needed)
1. Create a free account at github.com, then a new repository (any name).
2. Unzip this file. In the repo click "Add file" > "Upload files" and drag in EVERYTHING
   (including the hidden ".github" folder; if you can't see it, enable "show hidden files").
3. Commit. Open the "Actions" tab; the "Build APK" run takes ~3-5 min.
4. Open the finished run, download "StreamBrowser-apk" at the bottom, unzip it, and drag
   app-debug.apk onto BlueStacks.
